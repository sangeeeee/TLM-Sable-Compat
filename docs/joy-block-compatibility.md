# 休闲方块与座位（0.0.1-beta）

电子琴、电脑、书架共用 `touhou_little_maid:sit` 座椅实体。原先没有向 Sable 注册这种座椅的驻留方式，而兼容代码自行将座椅放到世界坐标，绕开了 Sable 对结构内载具的乘客投影和客户端渲染处理。此次统一采用 Sable 的结构内载具机制。

## 内置数据

- `data/sable/tags/entity_type/retain_in_sub_level.json`：座椅保留在结构局部坐标。乘客仍由 Sable 放置在对应世界位置。
- `data/sable/tags/entity_type/destroy_with_sub_level.json`：结构移除时同步移除座椅，避免留下无方块的幽灵座位。

标签随兼容模组打包，使用 `replace: false`，不覆盖其他模组的标签条目，无需额外安装数据包。所有使用同种座椅实体的方块都能获得这一层支持，包括棋盘座位。

玩家依原模组操作，空手右击方块入座；正常潜行下座。座椅的位置、旋转和乘客投影交给 Sable，兼容层只维护方块锚点生命周期和女仆朝向。普通世界座椅继续原有行为。玩家乘坐不套用女仆寻路的倾斜限制。

## 女仆休闲

结构上的休闲目标仍受当前结构、Home／罗盘活动区域限制，并排除已占用方块。发现休闲方块时，验证能否到达邻近的可交互站位，而不是要求走入方块本身；这解决电脑等不可直接走入的方块被过滤的问题。

走近与入座分别检查距离、空间与遮挡。保留原有搜索频率、入座距离和休闲收益逻辑。女仆在 IDLE 日程中持续使用；日程变化、Home 状态变化、结构倾斜超出原有寻路限制或锚点失效时按现有规则离座。

座椅锚点继续使用结构生命周期记录，支持正常方块搬移；拆掉方块或移除结构会释放座椅和乘客。此实现不迁移旧座椅保存格式。

## 测试

新增独立 `joy` 批次，验证玩家通过真实方块使用入口在电子琴、电脑、书架上入座并持续乘坐，平移／旋转后的乘客位置、下座、拆方块和移除结构，以及普通世界回归。测试玩家使用支持原生乘坐的 GameTest MockPlayer，NeoForge FakePlayer 的 `startRiding` 固定返回 false，不能用于此场景。

女仆测试使用罗盘等价的工作／休闲／休息绑定与 IDLE 日程，验证发现电脑、寻找可达的邻近站位、实际入座、持续休闲、随结构运动、世界朝向，以及日程切换时释放座位。保留原电子琴搜索及入座回归。

这些是服务器 GameTest，不替代完整整合包客户端和多人联网实测。

最终基础环境 31 项、可选附属模组环境 48 项 GameTest 全部通过，构建成功。回归过程中原有不可达平台测试曾出现偶发失败，重跑通过；已为该断言补充实际路径诊断，未修改寻路核心来绕过断言。
