# Maid Tavern 与 Sable

适用版本：Maid Tavern `1.2.0`、Kaleidoscope Tavern `1.2.0-neoforge+mc1.21.1`、车万女仆 `1.5.3`、Sable `2.0.5`。本模组版本仍为 `0.0.1-beta`。

## 已核对的任务

依据当前依赖 JAR 的 `LittleMaidCompat.addMaidTask` 和实际行为类，该版本只注册两项可选择的工作：

| UID | 工作 | 适配内容 |
| --- | --- | --- |
| `maidtavern:grape` | 收获葡萄 | 复用公共局部搜索、寻路和到达判断；额外检查悬挂葡萄本身的结构、活动区与遮挡，保留好感度决定的采收高度及剪刀规则 |
| `maidtavern:brewing` | 酿酒 | 箱子取料、酒桶选择、桶盖投料、放瓶接酒、收瓶、成品及副产物入库 |

`TavernExtraMaidBrain` 还加入自动饮酒行为，直接使用女仆手持或背包物品，不搜索外部工作方块，保留原逻辑。没有发现额外的独立工作任务。

## 规则与修复

- 跟随模式使用主人被 Sable 选中的结构，女仆尚未到达时不接活；Home 模式使用绑定结构。所有检查复用现有 `Work` / `Homes` 规则，包括无安全落点时的等待结构。
- 河童罗盘的当前活动区中心和半径同样约束葡萄、酒桶、箱子和酒瓶。手动绑定酒桶或箱子不能绕过范围和结构限制。活动区变化或绑定失效时，停止不再合法的作业。
- 葡萄任务寻找地面目标后会向上寻找实际葡萄，因此还要检查实际葡萄地址，防止从合法地面采收到区域外或被楼板挡住的葡萄。
- 酿酒使用自己的 `BrewingWork` 记忆。原版直接比较世界中的女仆与结构存储坐标，距离会极大；现改为在统一坐标中比较，并检查可见性。
- 原版只确认桶旁有路径，却仍把行走目标设为桶盖中央；其每秒的路径维护也会重设这个目标。适配后保留工作方块地址，另选可达站位，路径维护继续使用站位。
- 酒桶是 3×3×3 多方块结构；射线允许命中同一个桶的顶层，不能穿过外部墙壁、楼板或另一个桶。保留原任务到桶盖中心的 2.5 格距离；必要时应像普通世界一样给桶盖旁提供台阶或工作平台。
- 保留箱子 3 格、酒瓶 2 格的原交互距离、酿酒清单、指定容器、品质、原料数量及操作间隔。女仆离开交互范围时停止投料；同一合法酒桶的部分投料进度保留，可重新靠近继续。
- 继续使用上游的酒桶/箱子绑定数据；结构平移和旋转不改变方块存储地址。分裂导致地址改变时，需要用 Maid Tavern 的工具重新选择酒桶或箱子。不会跨结构操作旧地址，也不添加旧存档迁移。

搜索复用公共 BFS；站位候选数量有上限，重试沿用上游每 20 tick 的维护间隔和次数上限。没有增加全世界或其他结构的遍历。Maid Tavern 保持可选、仅编译依赖。

## 验证

```powershell
.\gradlew.bat runGameTestServer -PtavernTests
.\gradlew.bat runGameTestServer build
```

`tavernTests` 仅在开发运行环境加载 Maid Tavern、森罗酒馆及森罗厨房；与 `addonTests` 同时启用时不会重复声明。正常构建不会将它们加入运行依赖或打入成品。

新增六项服务器 GameTest 使用真实任务类和方块实体：

1. 移动并旋转结构上的成熟葡萄搜索、到达和剪刀采收。
2. 从绑定箱子取得空瓶和真实配方原料、选择桶旁可达站位、加入四桶水、中断后继续投料并关盖。
3. 放置空瓶、实际酒桶出酒、收取成品、存入绑定成品箱。测试直接设置发酵完成状态，未等待完整发酵计时。
4. 隔楼板操作拒绝、其他结构目标拒绝、主人换结构后的旧工作失效。
5. 河童罗盘范围限制、日程活动区变化、罗盘分裂失效后的作业停止。
6. 普通世界中原有箱子取物行为。

结构姿态通过 Sable 的物理管线更新，避免直接改显示姿态后被质量更新恢复。导航测试检查真实路径和站位，随后将女仆移至站位验证交互，并非逐帧客户端行走实测。
