# 工作、休闲、休息与通勤

版本固定为 `0.0.1-beta`。实现基于 Minecraft 1.21.1、NeoForge 21.1.248、Touhou Little Maid 1.5.3、Sable 2.0.5；可选曲柄适配使用 MUHC 1.6.2 和 Create 6.0.10。

## 活动空间

Home 模式使用绑定结构及当前日程的区域。跟随模式优先使用 Sable 当前跟踪到的主人结构；女仆尚未进入该结构时不远程选择工作。主人飞离且没有安全世界落点时，保留女仆当前或最后安全停留的结构，允许在其中等待和活动。不搜索主人周围未被 Sable 选中的其他结构。

公共路径节点限制在当前所选结构内。意外离开结构后，跟随模式尝试到主人当前空间，Home 模式尝试回绑定区域。失去结构跟踪需持续至少 10 tick，传送失败每 20 tick 重试。主人飞行且没有落点时，已掉离等待结构的女仆尝试回到记住的安全位置附近。坐姿、拴绳、乘坐和睡眠继续遵守女仆的移动控制。

结构间不规划连接路线；只有找到安全落点才转移。结构移除、卸载及过度倾斜继续使用 Home 阶段的生命周期规则。不会强制加载目标结构。

## 方块与实体工作

- 公共 `MaidMoveToBlockTask` 搜索使用局部方块地址，候选必须在所选结构、当前活动范围内，并通过原有 BFS 可达性检查。
- 公共到达回调、种植收割、放火把和食物取用等入口转换交互距离；回调仍收到真正的方块地址，不把世界投影当成存储地址。
- 床、休闲方块、棋盘、蜂巢及家庭餐搜索统一过滤结构、活动区域和完整可达路径。POI 查询只枚举范围附近区块，不枚举局部坐标与世界坐标之间的空白区间。
- 实体搜索保留任务原有查询范围，结构 Home 的查询范围投影到世界空间。非战斗候选要求在同一结构、当前范围内且路径可达；实体移动目标转换为当前结构的局部地址。
- 战斗保留原任务的敌我筛选。目标可在当前位置被攻击时不追击；否则只选择结构内可达的攻击位置。无法从结构内接近或攻击的目标被拒绝。远程模式允许攻击射程和视线内的结构外实体。
- 战斗位置搜索采用保守预算：周围最多 16 格、有限采样、最多 12 次路径检查，结果短暂缓存。复杂甲板可能放弃实际上存在但未被采样找到的攻击位置。不会为攻击规划离开结构的路径。发生安全返回后短暂屏蔽此前攻击目标，避免立即恢复同一追击。

MUHC 保留自己的 Sable 曲柄交互流程。兼容层修正其 Home 查询中心、限制搜索区块数量，并要求能够在所选结构内操作曲柄。曲柄本体无需作为步行终点，详见 [后续曲柄与钓鱼修复](fishing-crank-fixes.md)。

附属任务复用上述公共搜索、传感器、到达回调或 Brain 移动入口时可以获得适配。完全自行查找方块、直接设置速度、自己计算武器射程或直接传送的任务没有统一入口，仍可能需要点对点支持。本次没有增加其他附属模组的专门适配。

## 河童罗盘与通勤

三个记录依次为工作、休闲、休息区域；少于三个点沿用女仆原本的缺省规则。各活动使用女仆配置中的对应半径，但工作目的地不会延伸到其他结构。

日程或 Home 模式改变时，停止先前的行为、释放床或休闲座椅、清除旧工作与移动目标，再按新的活动区寻找目标。同结构有完整路径时步行通勤；没有完整路径时才尝试目标区域附近的安全传送。

罗盘的同空间限制、32 格绑定检查、失败原因提示、失败不覆盖原配置均保留。结构分裂后，只要任一已记录活动锚点与其余锚点分属不同空间，整组绑定失效，提示重新绑定。

## 床和休闲座椅

女仆床仍使用原模组的占用状态与日程条件。睡眠位置随床所在结构的当前位置更新；醒来释放占用，并尝试安全起床位置。休闲座椅通过内置 Sable 实体标签保留在结构局部坐标，乘客位置和客户端显示由 Sable 转换，不再额外手动投影座椅。具体修复及测试见 [休闲方块说明](joy-block-compatibility.md)。

床和座椅的短期锚点使用同一结构生命周期账本，支持标准方块搬移。方块被替换、结构移除或无法安全使用时结束相关活动。活动结束后清理短期账本项；Home 和罗盘的永久撤销记录继续保留。

不支持在侧翻、倒置结构上睡眠或步行；不联合其他独立结构规划绕行。其他结构堆在甲板上时仍可物理阻挡路径，按讨论保留卡住、重试行为；传送检查仍会考虑这些碰撞。

## 数据约定

没有旧版本配置或存档迁移代码，旧罗盘的自动接入分支和旧格式提示已移除。当前格式正常保存、加载，以及游戏内装配和分裂引起的坐标更新仍然保留。

## 验证

通过真实 NeoForge、Sable 物理后端和女仆模组运行服务器 GameTest。本工作阶段初始基础配置共 22 项，加载 MUHC/Create 后共 23 项；后续钓鱼与曲柄测试已增加至 24/27 项。本阶段新增覆盖：

1. 实际成熟作物收割及公共方块到达回调。
2. 跟随目标结构与 Home 优先级，以及不连通方块不可达。
3. 喂养同结构可达动物，拒绝另一结构上更近的动物。
4. 结构 Home 下实体查询、结构外敌人的实际弓箭攻击及近战拒绝。
5. 女仆床搜索、入睡、平移和旋转后睡眠位置、起床释放占用。
6. 电子琴搜索、实际乘坐、座椅跟随姿态及日程切换离座。
7. 女仆意外掉离结构、主人飞行无落点时回到等待结构。
8. 实际罗盘记录和绑定三个区域，按日程切换范围，并检查通勤路径的每个节点都属于该结构。
9. 床被实心方块替换时醒来，以及坐姿控制和 Home 掉落返回。

既有 Home、分裂、卸载、移除、跨结构跟随、魂符释放、曲柄等回归测试也保留。测试使用 FakePlayer、显式结构跟踪及行为入口调用；它们验证服务器逻辑，不等于真实客户端网络同步或长时间驾驶实测。尚未运行完整 Earth2 Reborn 客户端验收。

游戏内建议验证：移动飞艇上的收割与喂养 → 同结构与结构外战斗 → 三活动区日程切换 → 电子琴随船移动 → 睡眠跨夜 → 意外掉落返回 → 三锚点分裂 → 曲柄工作。尤其观察快速转向时床和座椅的客户端显示。
